# ProjectLibre (fork)

ProjectLibre is a desktop project management application written in Java. This fork is based on
ProjectLibre 1.9.8 and changes mainly its user interface, Microsoft Project import and export, and packaging.

## Layout

- `projectlibre_build`: Ant build, packaging resources, license texts
- `projectlibre_core`, `projectlibre_ui`, `projectlibre_exchange`, `projectlibre_reports`: application modules
- `projectlibre_contrib`: bundled third-party libraries
